MICROSOFT HELP GUIDES — GITHUB PAGES WEBSITE

This site uses the supplied Roadrunner reference ZIP as a visual/layout guide: white sticky navigation, blue-to-teal gradient hero, rounded cards, responsive article directory and individual inner pages. It uses a Microsoft-blue palette and exactly three navbar buttons: Home, Login, Support.

Files: index.html (homepage, no article-title list), blog.html (searchable 100-title directory), login.html, support.html, style.css, assets/ (local SVG illustrations), articles/ (100 individual HTML pages), sitemap.xml and robots.txt.

Publish: extract the ZIP and upload the contents of this folder to the root of your GitHub Pages repository. Keep the articles and assets folders. Replace YOUR-GITHUB-PAGES-DOMAIN in sitemap.xml and robots.txt with your published domain.

The navbar uses internal pages only. This is an independent educational website and is not affiliated with Microsoft. It does not collect credentials or provide official account recovery.
